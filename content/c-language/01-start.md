# 环境与第一段 C 程序

欢迎来到人工智能协会的新生学习路线。这一章先完成开发环境准备，并认识一段最小的 C 程序。

> 正式讲义将根据协会提供的资料继续补充。当前页面用于展示课程结构和作业流程。

## 本章目标

- 知道源文件、编译器和可执行文件分别是什么
- 能创建、编译并运行一个 `.c` 文件
- 能看懂程序入口 `main` 和输出函数 `printf`

## 示例程序

```c
#include <stdio.h>

int main(void) {
    printf("Hello, AI Club!\n");
    return 0;
}
```

编译并运行后，应当看到控制台输出 `Hello, AI Club!`。

## 提交前检查

1. 源码能够无错误编译。
2. 程序能够正常退出。
3. 压缩包中不要包含体积很大的临时编译目录。
4. 在作业说明中写明使用的编译器或 IDE。
