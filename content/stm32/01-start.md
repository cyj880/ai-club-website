# 工具链与第一次点灯

这一章用于认识 STM32 开发的基本流程：创建工程、配置时钟与 GPIO、编译下载、观察硬件现象。

> 开发板型号、工具链和正式操作步骤将在协会提供现有资料后补充。请不要在型号尚未确认时直接照搬网络引脚配置。

## 本章目标

- 认识开发板、调试器和 USB 供电接口
- 能创建与目标芯片一致的工程
- 能编译、下载并运行 LED 闪烁程序
- 开始养成记录芯片型号、引脚和现象的习惯

## 推荐记录格式

```text
开发板：待填写
芯片型号：待填写
LED 引脚：待填写
有效电平：高 / 低
闪烁周期：待填写
```

## 安全提示

- 上电前检查供电电压和接线方向。
- 不确定引脚定义时先查阅开发板原理图。
- 下载失败时记录完整报错，不要连续更改多项配置。
